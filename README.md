# KDTC Mobile Scanner

หน้าเครื่องสแกนด้วยมือถือสำหรับ KDTC Activity Scan

Repository นี้ใช้สำหรับหน้าเครื่องสแกนภายนอกเท่านั้น ส่วนผู้ดูแล จอแม่ กิจกรรม และ Google Sheets ใช้ Apps Script เดิม

สถานะ: เตรียมการเชื่อมต่อ GitHub สำเร็จ กำลังพัฒนาหน้าสแกน ยังไม่มีเว็บพร้อมใช้งาน

หน้าสแกนต้องตรวจสิทธิ์เครื่อง จำเครื่อง และป้องกันบันทึกซ้ำผ่านระบบเดิม ไม่เก็บข้อมูลนักเรียนหรือโทเคนเครื่องใน repository
